# Sistema de Gestión de Pedidos - API REST

Este proyecto es una API RESTful desarrollada en Node.js y Express para la gestión básica de usuarios y pedidos comerciales. Permite registrar nuevos pedidos y consultar el historial de pedidos por usuario.

## 🚀 Prerrequisitos
Antes de comenzar, asegúrate de tener instalado:
- [Node.js](https://nodejs.org/) (v14 o superior)
- [npm](https://www.npmjs.com/) (v6 o superior)

## ⚙️ Variables de Entorno
El proyecto utiliza variables de entorno para la configuración. Crea un archivo `.env` en la raíz del proyecto basándote en el archivo `.env.example`:

```bash
cp .env.example .env
